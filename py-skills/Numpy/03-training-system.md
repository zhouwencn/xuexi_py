# NumPy 训练与考核体系

## 一、每个模块的七类训练

### 1. 模仿题

看完示例后，关闭示例，用相同机制解决数据不同的问题。

示例：看到 `np.linspace(0, 1, 5)` 后，手写生成 `-1` 到 `1` 的 9 个等距点。

### 2. 独立手写题

只给需求、输入和输出，不给函数框架。

示例：实现二维数组按列标准化，标准差为 0 的列输出 0。

### 3. 改错题

要求依次完成：

1. 预测实际结果或异常。
2. 定位错误行。
3. 解释底层机制。
4. 给出最小修改。
5. 添加能防止回归的断言。

### 4. 阅读题

对真实 NumPy 代码回答：

- 每个数组的 shape 和 dtype 是什么？
- 哪一步发生广播？
- 哪一步创建 view 或 copy？
- 哪一步可能产生临时数组？
- 输入会不会被修改？

### 5. 输出预测题

先写结果，再运行。重点覆盖：

- 多维切片
- 布尔索引
- 花式索引
- 广播结果 shape
- axis 聚合
- view/copy 修改影响
- NaN 比较
- 整数 dtype 行为

### 6. 重构题

把能运行但质量差的代码改成更清晰的数组表达：

```python
result = []
for value in arr:
    if value > 0:
        result.append(value * 2)
```

重构时必须同时说明：

- 语义是否完全一致？
- 输出类型是否变化？
- NaN 如何处理？
- 是否创建大型临时数组？
- 性能是否经过测量？

### 7. 综合题

至少串联四个知识点，例如：dtype 转换 + 有效值掩码 + 按列统计 + 广播填充 + 输入不变性测试。

## 二、按能力递进的训练清单

### Level 1：结构直觉

- 写出 20 个数组的 `shape`、`ndim`、`size`。
- 根据创建代码判断 dtype。
- 把二维数组画成行列格子。
- 对 15 个切片表达式先预测 shape。

通过标准：结构题正确率达到 90%。

### Level 2：选择与变形

- 一维/二维/三维索引各 10 题。
- 布尔索引和多条件筛选 10 题。
- 花式索引重排 8 题。
- reshape、转置、增减维 12 题。

通过标准：不靠试错写出目标 shape。

### Level 3：计算与广播

- 标量、同 shape 数组运算。
- 20 组 shape 广播判断。
- 按列标准化。
- 行向量和列向量加权。
- 用 ufunc 改写循环。

通过标准：能解释广播的每一个轴，而不是只给结论。

### Level 4：内存与可靠性

- view/copy 输出预测 12 题。
- 用 `np.shares_memory` 验证假设。
- 分析 `flatten` / `ravel` / `reshape`。
- 修复输入被意外修改的问题。
- 比较不同 dtype 的内存。

通过标准：能写出不意外修改调用方输入的数组函数。

### Level 5：性能与综合应用

- Python loop 与向量化基准。
- 识别临时数组。
- 大矩阵分块处理。
- 随机生成压力测试数据。
- 完成二维数据清洗与统计项目。

通过标准：既能优化，又能用测试证明结果没有变化。

## 三、阶段考试

### A 卷：闭卷手写（45 分钟）

1. 创建指定 shape 和 dtype 的数组。
2. 完成二维切片和条件筛选。
3. 判断三组广播兼容性。
4. 按 axis 完成统计。
5. 使用 reshape 构造行/列向量。
6. 解释一段 view/copy 代码输出。

### B 卷：调试（45 分钟）

修复以下类别：

- `ValueError: operands could not be broadcast together`
- `IndexError`
- `arr > 10 and arr < 20`
- `arr == np.nan`
- reshape 元素数不一致
- 基础切片意外修改原数组
- 整数 dtype 导致结果截断或溢出

### C 卷：综合编程（90 分钟）

实现 `clean_and_standardize(matrix)`：

- 接收任意二维 numeric-like 输入。
- 转成 `float64` 独立数组。
- 非有限值和非正值按列中位数填充。
- 常量列安全标准化为 0。
- 返回清洗数组、标准化数组和统计摘要。
- 不允许逐元素 Python 循环。
- 至少包含 8 个测试。

## 四、调试清单

遇到 NumPy 错误时依次检查：

```python
print(type(value))
print(arr.shape)
print(arr.ndim)
print(arr.dtype)
print(arr.size)
print(arr.strides)
print(arr.flags)
print(np.shares_memory(left, right))
print(np.isnan(arr).sum())
print(np.isfinite(arr).sum())
```

再回答：

1. 输入是否真的是 ndarray？
2. shape 是否符合算法假设？
3. dtype 是否支持当前值和精度？
4. 两个数组能否逐轴广播？
5. axis 是否是要折叠的维度？
6. 当前对象是 view 还是 copy？
7. NaN / inf 是否参与了计算？
